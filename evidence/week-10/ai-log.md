# AI LOG – KURSUSKU
## Dokumentasi Penggunaan Artificial Intelligence
### Praktikum Pertemuan 10

### 1. Tujuan Penggunaan AI

ChatGPT digunakan sebagai alat bantu dalam proses pengerjaan project KursusKu menggunakan framework Laravel. Penggunaan AI bertujuan untuk membantu memahami materi praktikum, menyusun kode program, memperbaiki kesalahan, dan melakukan pengujian terhadap fitur aplikasi.

### 2. Catatan Aktivitas Penggunaan AI

| No. | Aktivitas | Bantuan AI |
|---|---|---|
| 1 | Persiapan Project | Membantu memahami struktur project Laravel dan konfigurasi lingkungan pengembangan. |
| 2 | Database dan Migration | Membantu menyusun struktur tabel courses beserta field yang diperlukan. |
| 3 | Model Course | Membantu membuat model Course dan menentukan atribut fillable serta casts. |
| 4 | Controller | Membantu menyusun CourseController untuk mengelola data kursus. |
| 5 | Routing | Membantu mengatur route untuk fitur pengelolaan kursus. |
| 6 | Tampilan Daftar Kursus | Membantu membuat halaman untuk menampilkan data kursus dari database. |
| 7 | Form Tambah Kursus | Membantu membuat formulir input data kursus menggunakan Blade. |
| 8 | Validasi Data | Membantu menerapkan validasi kode, nama, biaya, kuota, tanggal, dan status kursus. |
| 9 | Fitur Edit dan Hapus | Membantu membuat fungsi memperbarui dan menghapus data kursus. |
| 10 | Perbaikan Error | Membantu menganalisis dan memperbaiki kesalahan pada kode program. |
| 11 | Test Matrix | Membantu menyusun skenario pengujian dan dokumentasi hasil pengujian. |
| 12 | Dokumentasi | Membantu menyusun daftar bukti dan dokumentasi pengerjaan praktikum. |

### 3. Contoh Penggunaan AI

Beberapa pertanyaan yang digunakan selama pengerjaan project antara lain:

1. Bagaimana cara membuat migration tabel courses pada Laravel?
2. Bagaimana cara membuat model Course?
3. Bagaimana cara menampilkan data kursus dari database?
4. Bagaimana cara membuat formulir tambah kursus?
5. Bagaimana cara menerapkan validasi pada formulir?
6. Bagaimana cara membuat fitur edit dan hapus data kursus?
7. Bagaimana cara memperbaiki error pada CourseController?
8. Bagaimana cara menyusun Test Matrix untuk pengujian aplikasi?

### 4. Hasil Penggunaan AI

Dengan bantuan ChatGPT, proses pengerjaan project KursusKu menjadi lebih terarah. AI membantu memberikan penjelasan, contoh kode, serta solusi ketika ditemukan kesalahan dalam proses pengembangan.

Hasil implementasi kemudian diperiksa dan diuji pada project Laravel KursusKu.

### 5. Kesimpulan

Penggunaan Artificial Intelligence dalam Praktikum Pertemuan 10 membantu proses pembelajaran dan pengembangan aplikasi KursusKu. ChatGPT digunakan sebagai alat bantu untuk memahami konsep, menyusun kode, memperbaiki kesalahan, serta mendokumentasikan hasil pengerjaan.

Meskipun menggunakan bantuan AI, setiap kode dan hasil implementasi tetap perlu dipahami, diperiksa, dan diuji oleh mahasiswa agar sesuai dengan materi praktikum.
